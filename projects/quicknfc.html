QuickNFC

A kiosk-mode Android application for a dedicated card terminal that identifies people from chip ID cards, NFC cards or barcodes and greets them on screen and by voice.

Developed at Rubuplus

AndroidNFCSmart cardDevice integrationKiosk

My role & ownership

I developed QuickNFC as part of my work at Rubuplus: the Android application that runs on a dedicated card terminal, including its integration with the device's card readers, LED and audio feedback, and testing on the target hardware.

Project context

Identity and access workflows often require mobile software to communicate with physical readers and respond clearly to different device states. QuickNFC represents hands-on work in this hardware-adjacent space.

Areas of work

  • Android application workflows for identity reading
  • NFC and device-connected interactions
  • User interface states around scanning and feedback
  • Integration-oriented debugging and validation

Engineering approach

The work centers on connecting Android UI behavior with device capabilities. In this class of application, predictable feedback, error handling and repeatable tests matter as much as the interface itself.

Engineering considerations

  • Device availability and reader permissions
  • Clear feedback when a scan cannot complete
  • Keeping the UI understandable during hardware interactions

Android device application

A representative example of practical Android development where the application must work alongside dedicated hardware.

Structure & technologies

  • Kiosk-mode Android application on a dedicated card terminal that starts on boot with the system UI hidden
  • Chip ID card reading over smart-card commands, contactless NFC and USB barcode input combined in a single reading flow
  • Card identifiers normalized so built-in and external readers return the same ID for the same card
  • Spoken Turkish greetings, LED and sound feedback for successful and failed reads
  • Jetpack Compose screens layered over continuously playing background video
